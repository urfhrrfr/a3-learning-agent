# 自然语言处理基础

## 学习目标
- 了解文本预处理、表示和分类流程。
- 理解词袋、词向量和上下文表示的差异。
- 能解释问答系统为什么需要检索和上下文。

## 核心概念
分词；词袋模型；TF-IDF；词向量；序列；文本分类；问答。

## 重点难点
文本含义依赖上下文，同一个词在不同语境中可能含义不同。

## 常见误区
- 中文处理只要按字切分。
- 词频高就一定重要。
- 大模型回答一定来自可靠资料。

## 示例讲解
学习系统从学生对话中抽取“线性代数薄弱”“偏好代码案例”等画像维度。

## 练习题草案
1. 选择：TF-IDF 中 IDF 主要反映什么？
2. 判断：停用词在所有任务中都必须删除。
3. 简答：词袋模型丢失了什么信息？
4. 代码理解：阅读关键词抽取代码，指出阈值作用。
5. 场景题：为画像对话设计三个可抽取字段。

## 拓展阅读建议
阅读文本表示、分类和信息检索基础材料。

## 实践任务建议
用 Python 统计一段学习反馈中的关键词频次。
