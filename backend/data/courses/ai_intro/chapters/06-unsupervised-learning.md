# 无监督学习

## 学习目标
- 理解聚类和降维的目标。
- 说明 K-means 与 PCA 的基本思想。
- 能判断无标签数据分析的局限。

## 核心概念
聚类；簇；距离度量；中心点；降维；主成分；可视化。

## 重点难点
无监督学习没有标准答案，结果解释依赖业务语境和后续验证。

## 常见误区
- 聚类结果一定代表真实类别。
- 忽视特征尺度对距离的影响。
- 只看二维图就做强结论。

## 示例讲解
根据学习行为把学生分成“稳定练习”“临时冲刺”“阅读偏好”等群组，用于推荐策略参考。

## 练习题草案
1. 选择：K-means 需要预先指定什么参数？
2. 判断：无监督学习不需要任何数据预处理。
3. 简答：降维为什么有助于可视化？
4. 代码理解：指出距离计算前未标准化的风险。
5. 场景题：如何解释学习行为聚类结果？
