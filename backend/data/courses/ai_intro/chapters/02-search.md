# 搜索问题与启发式搜索

## 学习目标
- 建模状态空间、初始状态、目标状态和动作。
- 比较广度优先、深度优先、代价一致和 A* 搜索。
- 理解启发函数对效率和最优性的影响。

## 核心概念
状态空间；路径代价；开放表；关闭表；启发函数；A*；可采纳性。

## 重点难点
启发函数不是答案，它是对剩余代价的估计。过强或不合理的启发可能让搜索偏离最优路径。

## 常见误区
- 把局部最短动作当作全局最优路径。
- 忽略重复状态检测。
- 认为启发函数越大越好。

## 示例讲解
校园导航中，状态是当前位置，动作是走到相邻地点，代价可以是距离或时间，启发函数可以是直线距离。

## 练习题草案
1. 选择：A* 的评价函数通常由哪两部分组成？
2. 判断：深度优先搜索一定能找到最短路径。
3. 简答：什么是可采纳启发函数？
4. 代码理解：指出未维护关闭表的搜索代码可能出现的问题。
5. 场景题：为图书馆到食堂路径规划设计状态和动作。
