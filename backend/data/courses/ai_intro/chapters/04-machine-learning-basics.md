# 机器学习基础

## 学习目标
- 理解训练集、验证集、测试集和泛化。
- 解释损失函数、优化、过拟合和欠拟合。
- 能用小例子说明机器学习流程。

## 核心概念
样本；特征；标签；训练；泛化；损失函数；过拟合；模型评估。

## 重点难点
训练效果和真实效果不是一回事。学习者需要把“拟合训练数据”与“适应新数据”分开理解。

## 常见误区
- 只看训练准确率。
- 把相关性解释为因果关系。
- 忽略数据分布变化。

## 示例讲解
用历史学习时长、练习正确率预测掌握度。模型不是记住每个学生，而是学习可迁移的规律。

## 练习题草案
1. 选择：测试集的主要作用是什么？
2. 判断：训练误差越低，泛化能力一定越好。
3. 简答：过拟合与欠拟合的表现有什么不同？
4. 代码理解：指出将测试集用于训练的风险。
5. 场景题：为课程推荐任务设计两个特征和一个标签。
