# 知识表示与推理

## 学习目标
- 说明命题逻辑、谓词逻辑和产生式规则的表达能力。
- 理解知识库、事实、规则和推理过程。
- 能判断一个规则系统适合解决什么问题。

## 核心概念
命题；谓词；规则；事实；前向推理；后向推理；本体。

## 重点难点
知识表示需要在表达能力和推理复杂度之间取舍。表达越丰富，不一定越容易计算。

## 常见误区
- 把自然语言句子直接当作可推理知识。
- 规则之间冲突时没有优先级或解释机制。
- 认为知识图谱可以自动保证事实正确。

## 示例讲解
学习诊断规则：如果学生连续错“过拟合”相关题目，并且解释中缺少“泛化”，则标记弱点为模型评价。

## 练习题草案
1. 选择：产生式规则通常由哪两部分组成？
2. 判断：谓词逻辑比命题逻辑能表达对象关系。
3. 简答：前向推理和后向推理有什么差异？
4. 代码理解：阅读 if-then 规则，指出触发条件。
5. 场景题：为学习画像设计两条诊断规则。

## 拓展阅读建议
阅读逻辑推理入门材料和知识图谱基本概念。

## 实践任务建议
用 Python 编写一个三条规则的学习弱点诊断器。
