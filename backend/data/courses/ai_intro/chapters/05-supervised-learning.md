# 监督学习

## 学习目标
- 区分分类和回归任务。
- 理解决策树、线性模型和常见评估指标。
- 能解释精确率、召回率和 F1 的适用场景。

## 核心概念
监督信号；分类；回归；决策边界；混淆矩阵；精确率；召回率。

## 重点难点
不同指标反映不同错误代价。类别不均衡时，准确率可能掩盖问题。

## 常见误区
- 所有任务都只用准确率。
- 把回归输出强行当作类别。
- 训练数据标签错误却只调模型。

## 示例讲解
识别“是否需要补充资源”是分类任务，预测“下一次测验分数”是回归任务。

## 练习题草案
1. 选择：二分类混淆矩阵包含哪些基本数量？
2. 判断：召回率越高，精确率一定越高。
3. 简答：什么时候更关注召回率？
4. 代码理解：阅读阈值分类代码，说明阈值变化影响。
5. 场景题：为错题推荐系统选择合适评价指标。

## 拓展阅读建议
阅读监督学习章节、模型评价材料和决策树可解释性案例。

## 实践任务建议
实现一个简单阈值分类器，计算准确率、精确率和召回率。
