# 7 分钟演示视频脚本

本脚本用于录制项目演示视频，也可以作为现场答辩时的讲解顺序。建议先启动后端和前端，再按下面路线录制。

## 0:00-0:40 背景与目标

讲解词：

> 我们的项目面向高校课程学习场景，解决三个问题：学生基础差异大、学习资源不够个性化、学习路径缺少反馈闭环。系统以“人工智能导论”为样例课程，通过对话式学习画像、多智能体资源生成、个性化学习路径和练习评估，形成从诊断到资源、再到评估调整的完整闭环。

屏幕操作：

- 打开首页 `http://127.0.0.1:5173`
- 简要展示左侧导航：工作台、学习画像、资源生成、资源库、学习路径、智能辅导、练习评估

强调点：

- 不是普通聊天机器人，而是面向课程学习闭环的多智能体系统
- 本地可运行，不依赖真实 API Key，适合稳定演示

## 0:40-1:30 对话式学习画像

讲解词：

> 传统系统常用长表单采集学生信息，我们改为对话式画像。学生只需要用自然语言描述基础、目标、困惑和偏好，系统会抽取知识基础、薄弱点、学习目标、偏好模态等画像维度，并维护画像版本。

屏幕操作：

- 进入 `/profile`
- 输入：

```text
我线性代数比较薄弱，希望多给 Python 代码案例和图解。
```

- 点击“发送并更新画像”
- 展示右侧画像面板：专业层次、当前章节、学习目标、认知风格、时间预算、掌握度、偏好和薄弱点

强调点：

- 画像包含多个维度，不是静态表单
- 后续资源生成和路径推荐会使用画像字段

## 1:30-3:20 多智能体资源生成

讲解词：

> 资源生成不是一次性调用模型，而是由多个智能体协同完成。KnowledgeAgent 负责检索课程知识，PlannerAgent 规划资源组合，多个资源智能体分别生成讲解、导图、练习、阅读、视频脚本和代码案例，ReviewAgent 最后检查来源、难度和安全状态。前端展示 Agent Trace，让生成过程可观察、可解释。

屏幕操作：

- 进入 `/generate`
- 点击“启动生成”
- 展示生成进度、Agent Trace、生成结果
- 点开一个资源卡片查看内容

强调点：

- 每个 Agent 都有输入摘要、输出摘要、来源引用和状态
- 一次生成 6 类资源
- 每份资源都带 `source_refs`、`review_status`、`created_by_agents`

## 3:20-4:30 资源库展示

讲解词：

> 资源库集中展示系统生成的学习材料。这里可以看到每份资源的类型、难度、来源、审核状态和创建智能体。资源格式支持 Markdown、Mermaid、JSON 和代码，既能讲概念，也能支撑练习和实践。

屏幕操作：

- 进入 `/resources`
- 使用类型筛选
- 依次点开不同资源，展示 Markdown、Mermaid 或代码内容

强调点：

- 多格式资源适配不同学习偏好
- 来源引用和审核状态用于降低幻觉风险

## 4:30-5:20 个性化学习路径

讲解词：

> 系统会根据学习画像、掌握度和生成资源，形成个性化学习路径。路径不是简单章节列表，而是包含每一步的目标、推荐资源、推荐理由和预计学习时间。

屏幕操作：

- 进入 `/path`
- 展示路径步骤，例如概念热身、分层练习、代码迁移
- 说明推荐资源 ID 与资源库中的资源相互关联

强调点：

- 路径和画像、资源、练习结果联动
- 推荐理由可解释

## 5:20-6:10 智能辅导

讲解词：

> 学生在学习过程中可以向智能导师提问。系统会结合当前课程知识和学习画像，返回文字解释、来源引用和 Mermaid 图，帮助学生理解抽象概念。

屏幕操作：

- 进入 `/tutor`
- 提问：

```text
为什么训练准确率高，测试效果仍然可能不好？
```

- 展示回答和 Mermaid 图

强调点：

- 回答服务于课程学习，不是开放域闲聊
- 图示解释适合概念理解

## 6:10-6:50 练习评估与路径调整

讲解词：

> 最后通过练习评估形成反馈闭环。学生提交答案后，系统生成分数、掌握度变化、优势、薄弱点和反馈，并基于结果调整下一轮学习路径。

屏幕操作：

- 进入 `/assessment`
- 使用默认答案或输入包含“过拟合、泛化”的答案
- 点击“提交练习”
- 展示评估报告和调整后的学习路径

强调点：

- 练习结果会反向更新画像和路径
- 系统形成“画像 -> 资源 -> 路径 -> 练习 -> 再推荐”的闭环

## 6:50-7:00 总结

讲解词：

> 这个 MVP 已经完成本地可运行的课程学习闭环，覆盖对话画像、多智能体资源生成、可观察 Trace、个性化路径、智能辅导和练习评估。后续可以接入真实大模型、真实课程资源库、用户登录和更完整的数据持久化。

收尾画面：

- 回到工作台 `/`
- 展示画像、路径、进度和最近资源
