# PPT 大纲（12 页以内）

1. 题目与团队：基于大模型的个性化资源生成与学习多智能体系统。
2. 背景痛点：学生基础差异、资源泛化、学习路径缺少反馈。
3. 解决方案总览：对话画像、多 Agent 生成、路径推送、评估调整。
4. 系统架构：Vue 前端、FastAPI 后端、SQLite、MockLLMProvider、课程知识库。
5. 多智能体协同：Profile、Knowledge、Planner、资源生成、Review、Assessment。
6. 对话式学习画像：10 个维度、版本更新、弱点识别。
7. 个性化资源生成：讲解、导图、练习、阅读、视频脚本、代码案例。
8. Agent Trace 与防幻觉：来源引用、审核状态、进度追踪。
9. 学习路径与资源推送：时间线、推荐理由、资源关联。
10. 智能辅导与练习评估：问答、提交练习、掌握度报告、路径调整。
11. 创新价值与应用前景：高校课程、可扩展知识库、可接真实模型。
12. 总结与演示入口：本地运行方式、完整闭环演示。
