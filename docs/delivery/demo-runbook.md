# 项目演示 Runbook

本文档是答辩、录屏、现场展示时的“照着走”版本。建议先完整走一遍，再正式录制或答辩。

## 1. 演示前准备

启动后端：

```bash
cd backend
.venv\Scripts\activate
uvicorn app.main:app --reload
```

启动前端：

```bash
cd frontend
npm run dev
```

打开：

- 前端：`http://127.0.0.1:5173`
- Swagger：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/api/health`

建议正式演示前先执行：

```bash
cd backend
.\.venv\Scripts\python.exe -m pytest tests -p no:cacheprovider
```

```bash
cd frontend
npm run build
```

## 2. 7 分钟展示顺序

| 时间 | 页面 | 操作 | 要讲的重点 |
| --- | --- | --- | --- |
| 0:00-0:40 | 工作台 `/` | 展示总览指标和演示闭环 | 项目不是单点问答，而是“画像、资源、路径、辅导、评估”的学习闭环 |
| 0:40-1:30 | 学习画像 `/profile` | 输入学生情况并更新画像 | 自然语言生成学习画像，记录薄弱点、偏好、目标和掌握度 |
| 1:30-3:00 | 资源生成 `/generate` | 点击启动生成，展示 Agent Trace | 多智能体分工生成资源，过程可观察、可解释 |
| 3:00-4:00 | 资源库 `/resources` | 点开讲解、导图、练习、代码案例 | 一次生成多类型资源，支持 Markdown、Mermaid、JSON、Code |
| 4:00-4:50 | 学习路径 `/path` | 展示路径步骤和推荐理由 | 路径不是静态章节表，而是根据画像和资源推荐 |
| 4:50-5:40 | 智能辅导 `/tutor` | 提问并展示回答和图示 | 辅导回答结合课程语境，适合解释抽象概念 |
| 5:40-6:40 | 练习评估 `/assessment` | 提交练习，展示报告和路径调整 | 练习结果会反向更新掌握度、薄弱点和下一步路径 |
| 6:40-7:00 | 工作台 `/` | 回到总览页 | 总结完整闭环和后续扩展 |

## 3. 推荐输入

学习画像页输入：

```text
我线性代数比较薄弱，希望多给 Python 代码案例和图解。
```

智能辅导页输入：

```text
为什么训练准确率高，测试效果仍然可能不好？
```

练习评估页建议答案包含：

```text
过拟合会导致模型只记住训练样本，泛化到新数据时效果下降。
```

## 4. 答辩主线

建议始终围绕这句话讲：

> 本项目用对话式画像和多智能体资源生成，把课程学习从“统一材料发放”变成“基于画像和反馈的个性化学习闭环”。

三层展开：

1. 为什么做：学生基础差异大，资源和路径缺少个性化反馈。
2. 怎么做：Vue 前端 + FastAPI 后端 + SQLite 状态恢复 + 多 Agent 编排。
3. 做到了什么：画像、资源、Agent Trace、路径、辅导、评估报告全部可运行。

## 5. 现场展示注意事项

- 先启动后端，再启动前端。
- 如果页面没有资源，先到 `/generate` 点击一次“启动生成”。
- 讲 MockLLMProvider 时要说清楚：它用于稳定演示，系统保留了 Provider 抽象，后续可替换真实大模型。
- 讲异步任务时要说清楚：当前是同步执行 + job 状态模型，已经有 `queued/running/completed/failed`、progress 和 events，后续可平滑切换后台队列。
- 讲防幻觉时重点提：课程知识库、`source_refs`、`review_status`、Agent Trace。

## 6. 结束语

> 总结来说，这个项目已经完成一个本地可运行、可答辩展示的个性化学习 MVP。它覆盖对话画像、多智能体资源生成、可解释 Trace、个性化学习路径、智能辅导和练习评估闭环。后续接入真实大模型、多用户和课程平台后，可以扩展成更完整的智能学习系统。
